# Leen Summaqa: website redesign

A Jacquemus-inspired redesign of leensummaqa.com: white page, condensed black wordmark, full-bleed campaign photography, and products on grey plates in a tight 2-up grid.

- `index.html`: the whole site (HTML, CSS and JS in one file, no build step)
- `img/`: campaign and product images

## Run it

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```

To host it for free, enable GitHub Pages for this repository (Settings → Pages → Deploy from branch).

## What works

Product quick view with colour switching and image gallery, shopping bag and wishlist (saved in the browser), search, filters by model, menu, announcement bar and services carousels, newsletter form (front end only).

Checkout is not connected yet. Prices are in JOD.
